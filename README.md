# 短视频发布平台

整理 B站、小红书、抖音、微信视频号、知乎视频及微信公众号的发布方法，供创作者和 Agent 按平台实际页面执行。

2026-10-13 曾在原项目使用同一条视频完成五个平台的真实提交或发布，并保存公众号草稿。原项目中的小红书安全验证、视频号首次登录需要用户扫码；提交不代表审核通过。当前仓库是整理后的**流程和适配代码参考**，不是已完成一键发布的独立软件，后续平台页面变化需要重新核验。

## 从这里开始

1. 按 [多渠道发布指南](docs/多渠道发布指南.md) 准备成片、平台文案、封面和账号。
2. 复制 [发布包模板](examples/发布包模板.md)，填写本次渠道及字段，统一核对并获得发布授权。
3. 按 [平台操作细节](docs/平台操作细节.md) 逐一执行，保存脱敏回执；遇到提交状态未知时先核查，避免重复发布。
4. 如需开发自动化，阅读 [适配代码说明](references/adapters/README.md)。这五个文件依赖原运行时和真实平台页面，不能直接运行或保证跨账号复用。

微信公众号仅保存并回读草稿，正式发表由用户手动操作；视频号属于独立的视频发布渠道。

## 登录与隐私

账号登录和扫码在各自平台完成，登录资料只保存在用户自己的本机运行环境。不要提交 Cookie、token、密钥、浏览器 profile、截图、稿件、原视频或个人资料。仓库不含任何登录态、历史任务、实稿或原始回执；`.gitignore` 只是保护措施，提交前仍需审查内容。

本项目不收集账号，不提供平台官方 API，也不包含部署服务。使用前核对平台规则、自己的内容授权与当前界面。
