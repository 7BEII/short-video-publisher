# 发布包模板

复制到仓库外的本地工作目录后填写；这里是空白模板，不记录真实账号、视频路径或凭证。

## 成片

- 项目名称：
- 正式视频与时长：
- 内容来源与结论依据：
- 本轮渠道：
- 授权状态：待确认 / 用户已确认（写明确认版本）

## 每个平台复制一份

- 平台和账号：
- 标题或短标题：
- 正文/简介：
- 话题（分别列出）：
- 封面及比例：
- 声明、原创/转载：
- 分区、合集或领域：
- 可见范围、发布时间：
- 状态：待准备 / 待确认 / 已提交 / 审核中 / 已公开 / 结果未知
- 回执来源、时间、作品号或链接：
- 需要用户处理的事项：

## 公众号（只保存草稿）

- 标题、摘要与作者：
- 正文及图片：
- 封面与声明：
- 视频号原生卡片：需要 / 不需要
- 草稿保存和回读结果：
