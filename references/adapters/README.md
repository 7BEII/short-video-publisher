# 平台字段适配代码参考

本目录是从原项目整理出的五个页面字段模块，保留历史实现供阅读和后续迁移：B站、小红书、抖音、微信视频号、知乎视频。它们是代码片段，不含工作台、浏览器管理器、账号、素材、运行状态或发布任务驱动，**不是可直接运行的发布工具**。

前三个模块由原工作台的每平台独立工作线程驱动；视频号模块依赖独立 worker 和外部 `social-publisher` 的腾讯适配实现；知乎模块依赖独立的 Playwright worker 和任务状态。迁移时应自行补齐依赖和页面操作层，确认适用的上游开源许可，并验证真实页面。不得自行循环重试提交。

这些历史代码针对特定页面版本，知乎有固定话题/领域/AI 标记、确认文件和详情路径限制；具体见 [平台操作细节](../../docs/平台操作细节.md)。代码可以编译并不代表能在当前平台成功发布。
